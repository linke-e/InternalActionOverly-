========================================================
动画帧清单重建脚本 gen_anim.py
========================================================
功能
  扫描 resources/gfx/overlay_anim/ 下的所有子文件夹（每个动画一个文件夹，
  每帧一张 256×256 PNG），按文件名排序后生成 internalreactionoverlay_frames.lua
  （main.lua 运行时加载的动画帧清单）。

如何运行
  把脚本放在 mod 根目录（与 main.lua 同级），在该目录开终端执行：
    python "~\SteamLibrary\steamapps\common\The Binding of Isaac Rebirth\mods\InternalReactionOverlay+ 内置反应桌宠+\gen_anim.py"

何时需要重新运行
  · 往 overlay_anim/ 里新增/删除/改名动画帧后
  · 更换整套动画素材后

动画文件夹 → 动画键 对照（键在 config.lua 的 events/main/idle 里引用）
  overlay_main.png    -> main_static（单帧静态）
  overlay_main/       -> main（2 帧循环）
  overlay_boss/       -> boss
  overlay_death/      -> death
  overlay_death1/     -> death1
  overlay_half/       -> half
  overlay_hurt/       -> hurt
  overlay_hurt1/      -> hurt1
  overlay_idle1..5/   -> idle1..idle5
  overlay_itemnear/   -> itemnear
  overlay_itemnear1/  -> itemnear1

输出怎么看
  脚本末尾会打印每个动画的帧数，例如：
    internalreactionoverlay_frames.lua 已重建(16 个动画):
      boss            3 帧
      death          14 帧
      ...

素材来源（TangTang）
  原素材在 ~\InternalReactionOverlay+ 内置反应桌宠+\resources\gfx\overlay_anim
  想更换素材：直接替换 PNG 后重新运行 gen_anim.py 即可。
